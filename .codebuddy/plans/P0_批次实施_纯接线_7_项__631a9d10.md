## 产品概述

P0 的共同特征是「内核能力已就绪，只差最后一公里」：分页器已经算出页底注但没人渲染；表格已有 colspan/rowspan 但没有合并命令；标注模型完整却没有任何消费方；统计是纯函数但没有界面；阅读器已有键位与触屏却缺双指缩放；EPUB 校验函数已存在但没有命令行入口。本批把这些能力接到编辑器、阅读器、Vue 组件、导出器与 CI 上，使它们真正可用、可测、可发布。

## 核心范围

- **B5**：页底注区渲染（注区槽位、分隔线、续前页标记、超长注兜底）。
- **C4**：表格合并 / 拆分单元格命令与工具条接入。
- **C6 + D2**：选区建评论、标注侧栏（书签/高亮/笔记/评论）、点击定位、标注导出 Markdown、EPUB/站点导出的评论开关。
- **C9**：文档统计组合式 + 状态栏组件（字数/块数/阅读时长/章节分布）。
- **D4**：阅读器双指字号缩放、滚动模式键盘翻页。
- **E9**：EPUB 校验 CLI、fixtures 与 CI 校验步骤。
- **批次收口**：全量 build/test/typecheck、changeset、docs 回写、单条提交文本，然后停下等待确认。

## 技术栈

沿用现有栈，**不新增任何第三方依赖**：pnpm monorepo + TypeScript（strict / ES2020）、Vue 3、ProseMirror、vitest（node / happy-dom）、tsup、turbo、fflate、GitHub Actions。新增的 Vue 组件沿用 `Bt*` 命名与 props/emit 约定，样式只进 `buildBookCss` 的 `scoped()` 作用域。

### 1. B5 页底注区渲染

- **数据源不改**：`PageItem` / `PaginatedPage.notes` / `noteMainSize` 已由 `packages/layout/src/paginator.ts` 产出，`Reader.getPageNotes()` 已能把块 id 还原为 IR 节点。
- **序列化**：新增 `packages/layout/src/html/page-notes.ts`，仿照 `page-gutter.ts` 的「纯函数返回 HTML 字符串」范式：非文本注节点逐个 `serializeNode`，输出 `bt-page-notes` 容器与每条的 `bt-page-note`（带 `data-note-id`、注码沿用节点 attrs）。
- **续注**：`PaginatedPage` 增可选 `notesCarried?: boolean`（本页注区承接上一页溢出注时置真），`Reader` 增 `isPageNotesContinued(pageIndex)`；序列化据此输出 `bt-note-continued`「续前页」。**「接下页」不做**：内核目前不知道注文后续是否还有内容，不臆造标记（在 docs 中注明）。
- **超长注**：分页器注释已说明「单条超限独占一页，交由渲染侧截断/拆条」。本批只做**不裁剪的完整呈现 + 注区高度上限告警**（`data-overflow="true"`），按行拆条留待后续（避免在渲染层重复实现分页逻辑）。
- **样式**：`book-css.ts` 增注区规则（与正文同宽、`border-block-start` 分隔线、注文字号/行距、悬挂缩进、直排按列宽收束），全部经 `scoped(containerSelector)`，颜色/边框复用现有主题令牌。
- **Vue**：`BtBookView` 计算 `pageNotesHtml`（数据来自 `reader.getPageNotes` + `reader.isPageNotesContinued`），在 `flow` 与 `footer` 之间插入 `bt-page-notes`；page 与 scroll 两种模式都输出。
- **验收**：矮页 3 条脚注时第 1 页显示前 2 条、第 2 页显示剩余 1 条且带「续前页」；注区不进入正文流、不重复渲染；横排/直排各一例。

### 2. C4 表格合并 / 拆分

- 数据层不动：`table-cell.colspan/rowspan/align` 与 HTML 导入导出已具备。
- 新增 `packages/editor/src/table-merge.ts`（保持 `commands.ts` 单文件职责），导出 `mergeCells` / `splitCell`：
- 用 `$from` / `$to` 的节点路径定位单元格，校验同表、连续矩形、不跨表头行冲突；非矩形/跨表返回 `false`，**不派发事务**（无半合并状态）。
- `mergeCells`：左上格保留，其余格文本段落按顺序追加（空段落跳过，Word 行为），写 `colspan` / `rowspan`，删除被并格。
- `splitCell`：按 `colspan` / `rowspan` 补空 `table-cell`（内含空段落，满足 PM 内容表达式）并清空 attrs。
- `packages/editor/src/index.ts` 具名导出两个命令与类型；`apps/demo/src/components/EditorToolbar.vue` 加「合并 / 拆分」按钮与禁用态（复用现有 `execute` / `binding` 口径），同步修正工具条里「无跨行 / 跨列」的过期文案。
- **验收**：3×3 选 2×2 合并后为单格 `colspan=2,rowspan=2` 且其余 3 格消失、内容拼接；拆分恢复 4 个空格；非矩形不改文档；测试覆盖矩形/非矩形/表头冲突/直排渲染。

### 3. C6 + D2 批注与标注侧栏

**依赖调整（需随本计划一并确认）**：`packages/vue` 新增内部依赖 `@bibliotype/annotation`。理由：侧栏与评论创建必须消费标注模型，`annotation` 只依赖 `core`，方向为 `vue → annotation → core`，无环、无越层；同步更新 `packages/vue/package.json`、`开发规范.md` 依赖矩阵与 `docs/06`。

- **创建**：新增 `packages/vue/src/use-annotations.ts`，从 `EditorBinding` 选区取 `Anchor`，调 `createComment` / `createHighlight` / `createNote` / `createBookmark`（annotation 包已有），通过宿主传入的 `AnnotationStorage` 持久化（demo 内用 localStorage 适配器，私有应用实现，不进库）。
- **聚合**：不新增 reader API（reader 不得依赖 annotation）。在 `use-annotations` 内用 `resolveAnnotations` + `groupAnnotationsByNode`，再借 `findNodeTrail` 归到最近的结构节点，产出「按章分组」视图模型。
- **侧栏**：新增 `packages/vue/src/components/BtAnnotationSidebar.vue`，四个 tab（书签 / 高亮 / 笔记 / 评论），按章折叠分组；props 只收视图模型与只读标志，emit `locate` / `reply` / `resolve` / `remove`；点击定位由宿主调 `reader.goToNode` 或 `selectRange`。**不做**正文内高亮装饰（D9 范围）。
- **导出 Markdown**：新增 `packages/annotation/src/markdown.ts` 的 `annotationsToMarkdown(document, annotations)`（纯函数，可测），输出章节标题 + 书签/笔记/评论摘要。
- **评论导出**：`core` 新增跨包契约类型 `ExportComment`（`anchor` + `body` + `author?` + `createdAt?`）；`exporter-epub` / `exporter-site` 增 `includeComments`（默认 `false`）与 `comments` 入参，开启时在锚点所在章节末尾输出 `<aside class="bt-comment" epub:type="sidebar">`（EPUB）或等价区块（站点），正文转义。**exporter 不新增对 annotation 的依赖**。
- **demo**：用 `BtAnnotationSidebar` 替换 `BookmarkPanel.vue`（旧页级书签数据不强制迁移，保留降级提示），接入评论回复/解决/定位。
- **验收**：选中文本建评论 → 侧栏出现线程 → 点击回原选区 → 解决状态刷新后仍在；默认 EPUB 不含评论，`includeComments: true` 后含且不影响脚注 `<aside>` 语义。

### 4. C9 文档统计 UI

- 新增 `packages/vue/src/use-document-stats.ts`：入参 `document` + 可选 `revision`，内部 300ms 防抖调 `countDocumentStats`，返回 `DocumentStats`。以「文档引用变化 / revision 变化」触发，避免深度监听整棵 IR。
- 新增 `packages/vue/src/components/BtDocumentStats.vue`：纯展示，props `stats`、`compact?`、`selectable?`；显示字数/块数/阅读时长/注释数，章节分布用纯 CSS 条形（宽度按占比，不引图表库）；emit `select-structure`。
- demo 状态栏挂载；章节点击复用 TOC 同款 `goToNode` 口径。
- **验收**：数字与 `countDocumentStats` 输出一致；连续输入不触发每键全量统计；切换文档 300ms 内刷新；无新增依赖。

### 5. D4 双指缩放 + 滚动键盘

- `BtBookView` 新增可选 `fontSize?: number`（px）与 `update:fontSize` 事件；未传入时从 `FONT_SIZE_TOKENS.BODY` 读取。内部 tokens 计算把字号覆盖为当前值，视觉立即生效。
- 双指：在 page 模式容器上以 `addEventListener('touchmove', handler, { passive: false })` 跟踪两指距离，比例映射为 ±1px 档位（12–32 夹紧），手势期间 `preventDefault`；距离变化不足阈值不触发，避免抖动；结束不重复 emit。
- **重排责任在宿主**：组件只 emit，demo 在监听里按既有 `tokenPatch` 流程落盘并走既有 `repaginate({ measure })` 管线（demo 已有字号双通道联动），组件不擅自覆盖宿主的实测映射。
- scroll 模式：容器补 `tabindex="0"` 与 keydown（PageUp/PageDown/空格/Home/End 滚动一屏，带修饰键不拦截），补 `:focus-visible` 焦点环。
- **验收**：合成双指 TouchEvent 断言 emit 出 12–32 区间值；scroll 模式 PageDown 滚动且焦点不丢；`prefers-reduced-motion` 不受影响。

### 6. E9 EPUB 校验 CLI + CI

- 新增 `packages/exporter-epub/src/cli.ts`：纯逻辑 `runValidateCli(args, io)`（读文件 → `unzipSync` → `validateEpub` → 格式化 issue → 退出码），文件系统与输出可注入，便于单测。
- 新增 `packages/exporter-epub/bin/bt-validate-epub.mjs`：薄壳，仅转发到 `../dist/index.js` 导出的 `runValidateCli`；支持 `--json` 与 `--help`。
- `package.json` 补 `bin` 与 `files: ["dist", "bin"]`；`src/index.ts` 导出 `runValidateCli` 与类型。
- CI（`.github/workflows/ci.yml`）在 build 后增加一步：对 `fixtures` 的合法 EPUB 期望退出 0、损坏 EPUB 期望非 0，失败即中断。
- **验收**：`node packages/exporter-epub/bin/bt-validate-epub.mjs <ok.epub>` 退出 0；坏文件退出非 0 并打印 issue 码；`--json` 输出可解析；CI 出现该步骤。

## 架构设计

```
阅读/编辑数据流（本批新增部分）

IR ──paginate──► PaginatedPage.notes ──Reader──► BookNode[]
                                         │
                                         └─► serializePageNotes (layout/html)
                                                    │
Vue BtBookView ◄────────────────────────────────────┘（page / scroll 两种模式）

标注：Editor 选区 ─► Anchor ─► annotation(createX) ─► AnnotationStorage（宿主）
                                     │
                                     ├─► useAnnotations（vue，按章分组）
                                     │        └─► BtAnnotationSidebar
                                     └─► annotationsToMarkdown / ExportComment ─► exporter-epub / site
```

- **依赖方向**：`vue → annotation → core`（新增）、`vue → reader → layout → core`（既有）；exporters 只消费 `core` 的 `ExportComment`，不引 `annotation`。
- **职责边界**：layout 只出 HTML 字符串；reader 只做块/页查询；vue 只做视图与组合式；demo 只做挂载、持久化与示例数据；exporter 只做投影。
- **不加抽象层**：无状态容器、无新增事件总线、无新增插件机制，全部复用既有 `Reader` / `EditorBinding` / `AnnotationStore` / `buildBookCss`。

## 实施注意事项

- **样式作用域**：注区/侧栏新增 CSS 一律走 `scoped()` 或组件 `<style scoped>`；禁止全局选择器（会干扰编辑画布 `posAtCoords`）。
- **确定性**：注释 id 走既有 `buildAnnotationId`；测试与导出禁止 `Date.now()` / 随机数，时间由参数注入。
- **PM 合法性**：拆分单元格补空段落；合并跨格时按块节点重建内容，禁止把行内节点直接挂到 `table`。
- **性能**：统计防抖 300ms 且仅在引用/revision 变化时计算；注区序列化只处理 `page.notes`，不遍历全文档；侧栏分组按需 memo。
- **兼容性**：`notesCarried`、`fontSize`、`includeComments`、`ExportComment` 全为可选新增，不破坏既有调用方；不修改既有导出签名。
- **测试**：layout/editor/annotation/exporter 用 node；vue 用 happy-dom（只断言结构/事件，不依赖布局盒）。
