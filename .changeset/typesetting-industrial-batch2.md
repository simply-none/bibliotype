分页容量模型统一（排版工业级批次 2）

- **多栏回归「单序列 × 栏数容量」模型**：曾按块数把内容均分到各栏、每栏独立
  分页再按栏页合并——阅读顺序跨页错乱（文档序在后的小块出现在更早的合并页）、
  合并页丢弃页底注、keepWithNext 在栏切分点失效、与 CSS 多栏的顺序填充互相矛盾。
  现块沿主轴顺序装箱（页容量 = 栏容量 × 栏数），不可拆块放不进当前列剩余空间时
  对齐到下一列首（弃用列尾空白），与渲染侧 CSS 多栏行为一致。
- **页底注区记账修正**：首条注曾绕过全部容量检查无条件落页；后续注只按单条判，
  不累计注区高度——正文 + 多条注可叠出页底（500 + 60 + 60 = 620 排进 600px 页）。
  现按「正文入账 + 全部注区」累计判溢出；注文已占页时正文放不下另起新页
  （曾把放不下的正文也压进同页致重叠）。
- **分栏单通道**：分页器只认章节节点的 `attrs.columns`，设置面板的
  `options.columns` 分页器永远看不到（量尺按栏宽量、分页按单栏装、渲染开多栏
  三方各说各话）。现 `extractBlocksIndexed` 新增 `columns` 选项作全树缺省
  （结构节点 attrs 覆盖），Reader 与编辑态分页均已接入。
- **估算行构成修正**：默认估算器把「首行缩进扣减」误用于全部行（长段行数虚高、
  换页提前）；切片回退 `charRangeForLines` 又按均匀字宽切——两个口径互相矛盾，
  缩进段跨页切片错位丢字 / 重字。现新增 `estimateLineCount` /
  `estimateLineCharOffsets`（互为镜像的唯一事实源），估算器与切片回退同源。
- **groupNodesByBand 收口**：裸文本节点不再被静默丢弃（归最下截）；显式截位
  越界夹到最下截。
