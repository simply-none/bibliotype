古籍直排孤寡行预设落地修正（宽松口径真正到达 Reader）

**背景**：直排审计发现长段落（3~8 列）在剩余 1~2 列空间时**整段挪页**而非
拆分——宽松孤寡行预设只改到了现代横排主题，古籍直排 / 仿真直排主题的
替换未生效（文本不匹配），Reader 仍持严格 2/2：`minFirst=2` 下「只剩 1 列」
即触发整段挪页，制造大量 1~2 列的页底空白。

- demo `CLASSICAL_THEME` / `FACSIMILE_THEME` 的 layout 补上
  `widowControl: { minFirst: 1, minLast: 1 }`（宽松口径真正到达 Reader）。
- **实证**（同一本书，古籍直排）：页底空白 ≥1 列的页数 **539 → 30**（-94%，
  剩余全部为 keepWithNext 标题整组挪页——标题不孤悬页尾的最小约束）；
  全书 **1382 → 1349 页**（连排 + 满版累计 1608 → 1349，-16%）。
