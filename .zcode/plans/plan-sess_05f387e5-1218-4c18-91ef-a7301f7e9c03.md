# 仿真翻页 Demo 实施方案（apps/pageflip-demo）

## Context

上一轮调研结论：「完全仿真」的分水岭在于**页面内容是否沿曲面真实透视变形**——只有 WebGL 网格形变（iBooks/PARC 圆锥卷曲一脉）能做到；Canvas 2D 只能做裁剪+渐变近似，CSS 3D 是刚体翻页。目标即完全仿真、不可降级，故采用 WebGL 自研渲染。

仓库现状：无任何 WebGL 依赖；现有翻页动效仅 slide/fade（`BtBookView.pageTransition`）；已有竖排 RTL 方向约定（"直排右起：右滑=下一页"）；已有页面→位图管线 `createDomPageCapture`（`packages/vue/src/image-export.ts`）可作为未来 reader 集成的纹理桥。

**形态（默认，可推翻）**：单页占满视口（微信读书手机端样式）；demo 内容用程序绘制样张（横排文本 / 竖排直排 RTL / 画册图片三套），真实书籍接入留作集成下一步。

## 技术路线

- **原生 WebGL（GLSL ES 1.00，同一份着色器兼容 webgl2/webgl 上下文，最大化移动端兼容）**，零新增依赖——场景仅 2~3 个带纹理网格，three.js 无必要且规范上需新依赖论证。
- 页面位图贴到细分网格（约 48×72），**顶点着色器做卷曲形变**（每帧只更新 uniforms），片元着色器做光照。
- 引擎为**框架无关纯 TS 模块**（未来可提升为独立 package），demo 壳用 Vue 3（贴合仓库惯例）。

### 卷曲数学（curl-model + deform，纯函数可测）
- 角部拖拽：折痕 = 角点 C 与触点 T 连线的**中垂线**；边缘拖拽：折痕平行于书脊。
- 卷曲半径 r 随 T 逼近书脊收紧（f(|C−T|)，钳制 r_min/r_max），沿折痕轴向**线性锥化**产生圆锥感。
- 顶点映射（截面 s=到折痕有符号距离, z=高度）：s≤0 平贴；0<s<rπ 绕圆柱卷起（θ=s/r）；s≥rπ 平背延伸（z=2r，带可调 sag 下垂）——即 iBooks 式"大幅变形时摊平"。
- 触点约束（constraints）：以角点为圆心的钳制圆防折痕越过书脊、半径钳制、页内边界。
- RTL 竖排：几何 X 镜像 + 进度取反，同一套数学。

### 光照与阴影三件套（shaders）
翻起页：正面原纹理；背面 `gl_FrontFacing` → 镜像 UV + 纸色偏黄调 + 法线翻转。平行光漫反射 + 低强度 Blinn-Phong 纸面高光 + 折痕处 AO。下层页：片元按「到折痕有符号距离」渐变投影（折痕几何由 uniform 传入，随手势实时旋转/移动）+ 书脊常驻 AO。

## 实施阶段

1. **骨架**：新 app（复制 apps/demo 的 package/tsconfig/vitest 形态，无 vue-router），`apps/*` 通配自动纳入 workspace/turbo。
2. **几何内核**：constraints → curl-model → deform，纯函数 + vitest 金值测试（含 RTL 镜像 = X 取反断言）。
3. **GL 渲染**：shaders + gl-renderer + texture-store + page-provider；先静态卷曲姿态出图。
4. **交互**：input + flip-controller。拖拽实时驱动（1 帧低通滤波防抖不跟手）；松手判定 = 进度>0.45 **或** 速度>~0.5px/ms → SNAP_FORWARD，否则 SNAP_BACK（easeOutCubic + 纸张回弹微振荡，时长随剩余距离缩放）；点击角/边自动翻页；键盘 ←→/PageUp/Down；滚轮累积阈值；SNAP 可被新手势打断（连续快翻）。
5. **Demo 内容与打磨**：三套 provider（竖排用 canvas 逐列绘制真实感直排样张；画册用 picsum URL + 离线回退）；控制面板（provider 切换/页码/自动演示/网格调试/FPS）；dpr 钳制 ≤2、WebGL2 NPOT mipmap（WebGL1 退化线性）、纹理懒上传、`webglcontextlost/restored` 处理。
6. **测试与文档**：vitest（几何/状态机/LRU）；README + docs/23；`pnpm --filter @bibliotype/pageflip-demo typecheck`。
