# 双页对照模式修正计划

## Summary

修复 Demo「双页对照（当前文档左右对页）」的展示与交互：

1. 对照开启时**只展示两页**：用对照视图就地替换主区阅读画布，隐藏目录栏，不再叠加原正文；
2. **不出现页面级 / 容器内滚动条**，滚轮只用于翻页；直排（含古籍直排、古籍仿真直排）与横排一致；
3. 修复直排下原主区被挤到右侧成「小窗口」的网格错位问题；
4. 修复古籍仿真下纸色 / 字体与单页不一致（对照容器补齐主题令牌透传）；
5. 两页之间加可见中缝，不再「看起来是一整块」；
6. 移除对照标题条，把「关闭」改为「退出对照」并放到顶栏「逐页」按钮之后；
7. 进入编辑态时自动退出对照。

## Current State Analysis

### 根因 1：对照层是 `.app` 的普通子项，不在受限高度内

- [App.vue](c:\cod\note_npm\apps\demo\src\App.vue#L859-L872) 把 `app__compare-overlay` 追加在 `.app` 末尾。
- `.app` 是 `height: 100vh` 的 flex column（[app-shell.css](c:\cod\note_npm\apps\demo\src\styles\app-shell.css#L8-L27)）：
  - 横排：对照层作为额外行向下撑开，整个文档出现页面级滚动条，原正文仍露在上方（图三）；
  - 直排：`.app--rail` 是 5 列 grid（[app-vertical-rail.css](c:\cod\note_npm\apps\demo\src\styles\app-vertical-rail.css#L28-L64)），对照层无显式 grid 位置，被自动放进剩余列，`auto` 列宽被对照内容撑大，原主区（col 5，`minmax(0,1fr)`）被压成右侧小窗口（图一）。

### 根因 2：对照容器没有边界，`BtBookView` 退回 1:1 并产生滚动条

- [BtBookView.vue](c:\cod\note_npm\packages\vue\src\components\BtBookView.vue#L604-L616) 在 `fit='contain'` 时按 `root.clientWidth / Height` 求比例并 `Math.min(1, ratio)`；容器高度不定或过小都会让页面溢出。
- `.bt-book-view` 自身 `overflow: auto`（[BtBookView.vue](c:\cod\note_npm\packages\vue\src\components\BtBookView.vue#L1727-L1736)），一旦溢出就出现内部滚动条，滚轮翻页手感变差。

### 根因 3：两页之间没有中缝

- `SPREAD_GAP = 0`（[BtBookView.vue](c:\cod\note_npm\packages\vue\src\components\BtBookView.vue#L282-L283)），`spreadPageStyle` 的右页偏移也只按页宽算（[BtBookView.vue](c:\cod\note_npm\packages\vue\src\components\BtBookView.vue#L358-L365)）。
- `.bt-book-view__spread` 只有整体一层阴影（[BtBookView.vue](c:\cod\note_npm\packages\vue\src\components\BtBookView.vue#L1853-L1858)）。页纸同色且无缝，直排下两页内容直接连成一块（图一）。

### 根因 4：对照未透传主题令牌 / 字体 / 功能样式

- [BtCompareView.vue](c:\cod\note_npm\packages\vue\src\components\BtCompareView.vue#L61-L67) 的 `sharedProps` 只有 `mode / fit / pageTransition / flowChunkBlocks`，没有 `tokens / fontToken / fontSize / features / namedStyles`。
- 内部 `BtBookView` 回落到 `DEFAULT_THEME`，纸色、正文字体、功能样式与单页不一致（古籍仿真尤其明显，图二）。

### 相关现状（不改动部分）

- 对照开关在状态栏「双页对照」按钮（[AppStatusBar.vue](c:\cod\note_npm\apps\demo\src\components\app\AppStatusBar.vue#L172-L181)）与 H5「更多」sheet（[MobileMoreSheet.vue](c:\cod\note_npm\apps\demo\src\components\app\MobileMoreSheet.vue)）中，继续保持。
- `compareOpen` 由 `useExport` 持有（[use-export.ts](c:\cod\note_npm\apps\demo\src\composables\use-export.ts#L237-L238)），不改归属。
- 双文档对照（传 `right`）走 `BtSpreadLayout`，本次不动。

## Proposed Changes

### 1. `apps/demo/src/App.vue`

**做什么**

- 顶栏新增两个入参（见第 2 项）：`:compare-open="compareOpen"`、`:exit-compare="exitCompare"`。
- 删除模板末尾的 `app__compare-overlay` 整块（标题条 + 关闭按钮 + 对照正文）。
- 在 `.app__stage` 内改为「对照优先」渲染：

```html
<div v-if="booted && mode === 'read' && compareOpen" class="app__compare">
  <BtCompareView
    :left="readerRef"
    :tokens="tokens"
    :font-token="activeFontToken"
    :font-size="fontSizeNum"
    :features="features"
    :named-styles="namedStyles"
    mode="page"
    :page-transition="pageTransition"
  />
</div>
<BtBookView v-else-if="booted && mode === 'read'" ...原参数不变 />
<BtEditor v-else-if="booted && bookEditor" ...原参数不变 />
```

- 隐藏目录栏与拖拽条：`v-show="asideVisible && !compareOpen"`（两处）。
- 流式回落提示条加 `&& !compareOpen`，避免对照时出现无关提示。
- 脚本新增：

```ts
/** 退出双页对照：回到单页阅读 */
function exitCompare(): void {
  compareOpen.value = false;
}

/* 对照只属于阅读态：进入编辑（桌面 / H5 同一入口）时自动退出 */
watch(mode, (next) => {
  if (next === 'edit') compareOpen.value = false;
});
```

**为什么**：对照层进入受限的 `.app__stage` 后，直排不再被自动塞进 grid 列，横排不再撑开文档；目录栏隐藏后主区宽度全部给双页；编辑时不会出现「对照替换掉编辑画布」。

**怎么做**：`BtCompareView` 这次不传 `fit-scale`，由内部 `fit='contain'` 以舞台宽高为界缩放，保证不溢出。

### 2. `apps/demo/src/components/app/AppTopBar.vue`

**做什么**

- props 增加 `compareOpen: boolean`、`exitCompare: () => void`。
- 在「逐页 / 连续」按钮之后、同一 `toolbar__group` 末尾加：

```html
<button
  v-if="compareOpen"
  type="button"
  class="toolbar__button toolbar__button--active"
  title="退出双页对照，回到单页阅读"
  @click="exitCompare"
>
  退出对照
</button>
```

**为什么**：用户指定「关闭」文本改为「退出对照」，并放在「逐页」按钮之后；直排时按钮组整体竖排，按钮自动落在竖列末端。

### 3. `apps/demo/src/styles/app-shell.css`

**做什么**：在 `.app__stage` 规则后新增：

```css
/* 双页对照：就地占满阅读舞台，关闭容器内滚动（滚轮专用于翻页） */
.app__compare {
  height: 100%;
  min-width: 0;
  min-height: 0;
}

.app__compare :deep(.bt-book-view) {
  overflow: hidden;
}
```

**为什么**：给 `BtBookView` 一个确定高度，contain 缩放才有正确的 `clientHeight`；`overflow: hidden` 保证 1px 级舍入溢出也不冒滚动条，同时 `window`/页面级也不滚。

### 4. `apps/demo/src/styles/app-mobile-skeleton.css`

**做什么**：删除文件末尾 `@media (max-width: 767px) { .app__compare-bar { ... } }` 规则（对照标题条已移除）。

### 5. `packages/vue/src/components/BtCompareView.vue`

**做什么**

- props 增加（与 `BtBookView` 同名同义）：
  - `tokens?: Readonly<Record<string, string | undefined>>`
  - `fontToken?: string`
  - `fontSize?: number`
  - `features?: FeatureStyleSheet`
  - `namedStyles?: NamedStyleSet`
- `sharedProps` 计算属性把这 5 项一并透传。
- 顶部注释补一句：单文档对页与单页共用同一套主题 / 字体 / 样式来源。

**为什么**：修复古籍仿真纸色、正文字体、功能样式与单页不一致（根因 4）。这是库组件的能力补齐，不改任何既有行为。

### 6. `packages/vue/src/components/BtBookView.vue`

**做什么**

- `SPREAD_GAP`：`0` → `24`，注释改为「中缝宽度：留出画布色空隙，两页各自成张」。
- `spreadPageStyle` 右页偏移改为含中缝：

```ts
left: `${(page.index % 2) * (pageSize.value.width + SPREAD_GAP) * scale.value}px`,
```

- CSS：对页容器不再画整体阴影，改为每页各自投影：

```css
.bt-book-view__spread {
  position: relative;
  flex: none;
}

/* 对页：两页各有一层投影，配合 24px 中缝，读感是「两张纸」而非一整块 */
.bt-book-view__spread > .bt-reader-page {
  box-shadow: 0 2px 14px rgba(0, 0, 0, 0.18);
}
```

- `spreadWidth` 已含 `SPREAD_GAP`，`spreadStageStyle` 不变；缩放仍按「双页宽 + 中缝」计算。

**为什么**：解决直排 / 横排两页粘连（根因 3）；中缝与偏移同口径，缩放后比例不失真。

## Assumptions & Decisions

1. **保留顶栏与状态栏**：它们是应用 chrome（且用户要求退出按钮在顶栏、对照入口在状态栏），「只展示两页」指阅读区不再叠加原正文、目录栏隐藏。
2. **对照恒为分页 + contain**：不继承宿主「适宽 / 适高」的 `fitScale`（该倍率允许 >1，会溢出产生滚动条）。
3. **中缝固定 24px（随整页缩放）**：不新增对外配置；两页各自投影，替代原来的整体阴影。
4. **H5 不另加退出按钮**：H5 无「逐页」按钮，沿用「更多」sheet 里的「双页对照」开关退出；窄屏（<768）对页降级单页的既有行为不变。
5. **进入编辑即退出对照**：统一用 `watch(mode)`，覆盖顶栏 / 状态栏 / H5 sheet 三个入口。
6. 不动双文档对照（`right` + `BtSpreadLayout`）与 `compareOpen` 的持有位置。
