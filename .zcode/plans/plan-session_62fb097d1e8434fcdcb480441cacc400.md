## 文件内容（已定稿的完整计划，文档化组织）

1. **文档头**：目标、依据（《古籍排版要素整理.md》十六节 + 平台对标检索）、使用方式（每批完成后回写批次状态表）；
2. **规则速查表 R1–R16**：正文连排 / 夹注行内化（n 字占 n/2 字位、回行缩格）/ 低格顶格 / 抬头六式（含行末整组移行硬规矩与页首降级）/ 提行另起 / 标点占格 / 批注三层空间 / 书耳 / 鱼尾扩展 / 花栏眉栏 / 两截本三截本 / 墨钉 / 朱墨多色套印 / 圈点双位与注码圈码 / 卷末总评 / 插图版式 / 筒子叶对页与叶次 a/b / 图文对照（可选）；及明确不纳入项（避讳、复本特征、著录编目、扫描指标、装帧形制）；

5. **渲染与样式**：直排列盒渲染（宽=列距咬合界行）、夹注一格双行、装饰位（眉批天头 / 旁批界行外 / 书耳）、两截本分层、多色变量；
6. **reader / 量尺 / 分页**：成块口径收敛、实测与估算双路径折算、行级指令（breakLine 强制列首、抬头词组不拆）；
7. **编辑器**：spec / 命令（wrapDoubleNote、setIndent、setLift、toggleBreakLine、insertInkNail、insertGeneralReview、setInkColor）、PagedCanvas 列盒与选区桥、工具条「行款」分组；
8. **导出降级表**（EPUB / PDF auto / 站点）与 PDF paged 同源口径；
9. **七个批次**：每批范围 / 涉及文件 / 测试要点 / 文档同步 / 验收标准，附**批次状态跟踪表**（待启动 / 进行中 / 完成）；
