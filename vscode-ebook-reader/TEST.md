# 测试电子书阅读器插件

## 快速开始

### 1. 编译插件

```bash
cd vscode-ebook-reader
npm run compile
```

### 2. 运行插件

按 F5 或点击「运行和调试」按钮，会打开一个新的 VSCode 窗口加载插件。

### 3. 导入电子书

在新窗口中：
1. 点击左侧活动栏的「电子书」图标（书本图标）
2. 点击书库视图顶部的「+」按钮
3. 选择一个 txt/html/md 文件

### 4. 阅读

- 点击书库中的书籍标题即可打开阅读
- 滚动阅读时进度自动保存
- 顶部进度条显示当前阅读位置

## 配置测试

在设置中搜索「电子书」可以调整：
- 字体大小
- 行高
- 主题（亮色/暗色/护眼）
