量尺与渲染同源收口 + 编辑输入修复（排版工业级批次 3/4）

- **量尺交叉轴口径统一**：量尺工作表曾按方向无关地手扣页眉页脚（横排下它们
  侵占主轴、由 `resolvePageMainSize` 扣），横排行宽被系统性压窄
  headerSize + footerSize，量尺与渲染整体错尺。现直接采用渲染侧权威口径
  `resolvePageCrossSize`（方向性扣减 / 边框门控 / 单侧 none 均由其处理）。
- **量尺不再叠加多栏**：工作表定尺已是单栏宽，再开 `column-count` 会把栏宽
  二次除以栏数（2 栏时实测换行宽度 ≈ 版心宽 / 4），且 CSS balancing 使
  offsetTop 推进量错乱。
- **阅读态量尺接功能样式**（demo）：功能样式改行高 / 段距时阅读预览的分页
  归属曾按无功能样式的量尺计算，与渲染错尺（07ad411 只接通了编辑态）。
- **BtBookView 三模式渲染收口**：page / spread（对页）/ scroll（滚动）共用
  同一页正文组装器——曾出现对页与滚动模式退回块级流（直排「段段换列、
  版面半空」回归）、眉批 / 旁批同时进正文流与天头 / 界行外装饰位（双份）、
  跨页续排片段每页重发低格 / 断列前缀。打印 paged 分支的同类双渲染同批修复。
- **编辑输入偏移修正**：`charOffsetInFrag` 元素容器分支曾跳过全部容器后代
  文本，caret 落在元素中段 childIndex（行内字图 / 夹注旁）时前序子树文本
  漏计、落模偏移整体前移、打字落错位置。
- **编辑画布序列化缓存接通道键**：htmlCache 曾只按节点引用缓存，改字号 /
  页尺寸 / 书写方向后未重切片的整块片段复用旧 HTML（夹注子列容量陈旧），
  编辑与阅读视觉分叉；现缓存键随书写方向 + 夹注子列容量 + 片段起点行变化。
- **增量实测起点取块序最小提示**：去抖窗口内的多编辑提示曾取首个（编辑顺序），
  先编辑靠后块再编辑靠前块时漏测靠前块的尺寸变更；现按块序取最小者。
