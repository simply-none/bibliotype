## 修复「导出 EPUB 后部分阅读器加载失败 / 闪退」（P0）

**现象**：epub 导出后在部分阅读器加载不出来或闪退，原书（编辑态）无此问题。

**根因（实测）**：`dcterms:modified` 原样写入含小数秒的 ISO 时间（如 `2026-01-02T00:00:00.000Z`），违反 EPUB 3.3 硬性格式 `CCYY-MM-DDThh:mm:ssZ`，epubcheck 报 ERROR → 严格阅读系统拒绝打开/崩溃。OCF 容器（mimetype 首条目 STORE 无 extra）、XHTML/nav/container/OPF 的 XML well-formedness 经严格 `@xmldom/xmldom` parser 全过（0 issue），`<!DOCTYPE html>` 在 EPUB 3 允许（非 bug）。副标题写成第二个 `<dc:title>` 是 epubcheck WARNING（同语言多标题），非崩溃原因。

**改动**
- `packages/exporter-epub/src/opf.ts`：新增 `normalizeModified`（UTC 归并 + 去小数秒 + 字面量 Z，幂等，无效值回退当前 UTC）；`buildOpf` 内对 `input.modified` 归一；副标题改为 `<meta refines="#bt-title" property="dcterms:title" xml:lang>` 关联主标题（主标题加 `id="bt-title"`），消除 WARNING。
- `packages/exporter-epub/src/epub.ts`：取 `modified` 后先 `normalizeModified` 再用于 OPF 与 zip `mtime`，保证两者口径一致。
- `packages/exporter-epub/src/index.ts`：导出 `normalizeModified`。
- `packages/exporter-epub/src/__tests__/epub.test.ts`：断言改为 `meta refines` 副标题 + 无 `.000Z`；+2 用例（时区偏移归 UTC、normalizeModified 幂等/回退/格式）。

## 三次修复「京东读书仍打不开」（方案 B：去 EPUB3 残留，补全为合规 EPUB 2.0）

**背景**：方案 A（version=2.0 + toc.ncx）后京东读书桌面版仍"加载中"打不开。对比能开的《诗经》原书（Calibre EPUB 2.0）逐文件比对，定位残留冲突。

**根因**：导出虽声明 `version="2.0"`，但残留 EPUB 3 专属结构，RMSDK 按 EPUB 2 解析 `version="2.0"` 包遇之解析失败 → 卡死。具体：(1) OPF 含 `<meta property="dcterms:modified">` 与副标题 `<meta refines …>`（EPUB3 专属 `property` 属性，RMSDK 不认）；(2) 内容 XHTML 用 HTML5 `<!DOCTYPE html>` + `<meta charset>`，非 EPUB2 要求的 XHTML 1.1 + http-equiv Content-Type；(3) nav 条目带 EPUB3 `properties="nav"`；(4) 缺 `xmlns:opf`/`dc:date`。

**改动**
- `opf.ts`：引入 `epub3 = version==='3.0'`；仅 `epub3` 时输出 `<meta property="dcterms:modified">` 与副标题 `refines`；非 3.0（即 2.0）改以 `<dc:date>` 承载日期；补 `xmlns:opf`；`version` 声明提前到函数顶部（修 TDZ：原 `const epub3 = version===...` 早于原 `version` 声明 → `Cannot access 'version' before initialization`）。
- `epub.ts`：`const epubVersion: string = '2.0'`（原 `'2.0'` 被推断字面量，`=== '3.0'` 触发 TS2367 dts 构建失败 → 加 `: string`）；nav 条目 `properties` 按 `epubVersion==='3.0' ? 'nav' : undefined`。
- `xhtml.ts`：doctype 改 XHTML 1.1（`PUBLIC "-//W3C//DTD XHTML 1.1//EN" …`）；`<head>` 以 `<meta http-equiv="Content-Type" content="text/html; charset=utf-8"/>` 替代 `<meta charset>`。
- 测试 `epub.test.ts`：断言改 EPUB2 路径（无 `meta refines`/`dcterms:modified property`、有 `dc:date`、nav 无 `properties="nav"`、metadata 含 `xmlns:opf`），新增 XHTML1.1 doctype/Content-Type 断言；EPUB3 路径 `dcterms:modified` 规范化改由 `buildOpf({version:'3.0'})` 直测保留覆盖。
- `.changeset/exporter-epub-dcterms-modified-normalize.md`：更新覆盖方案 B。
