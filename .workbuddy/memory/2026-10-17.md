## EPUB 导出兼容性诊断（京东读书/微信读书打不开）

- 实测（kitchen-sink 样本导出 + Python 严格 XML 解析 + zip 结构校验）：mimetype 首条目 STORE / container / OPF / manifest / spine / ncx 锚点 / UTF-8 无 BOM / 全部 XML 条目格式良好——**容器层完全合规**，「EPUB 2 保守策略」防守错了对象。
- 最可能根因（内容层，与主流工具做法相反）：
  1. 导入型书籍图片经 inlineImages（默认 true，from-epub.ts:300）变 data URI，exporter 原样写回 XHTML → RMSDK data URI 兼容差 + base64 膨胀 + 平台体积限制；自建书图片 src 是本地/外链 → 死链。exporter 零媒体收集。
  2. style.css 全量 CSS Variables + var()（book-css.ts），RMSDK/微信读书老引擎不支持 var() → 样式整体丢弃（能打开但无排版）。
  3. 元数据非平台习惯：identifier=urn:bibliotype:hash（非 ISBN/UUID）、无封面 meta 声明。
  4. 「2.0 OPF + 无 properties 的 nav.xhtml + XHTML1.1 DOCTYPE 含 HTML5 nav 元素」非标准混合态；docs/07 还写 EPUB 3，已与代码漂移。
- 已给改造清单（P0 媒体打包/封面约定/导出前校验器/元数据；P1 CSS 扁平化/样式空洞/直排降级/版本策略/文档壳；P2 体积/分节/导入侧对称/真机矩阵），等用户确认再动手。
- 环境备忘：本会话 Bash 工具 PATH 损坏（无 coreutils），PowerShell stdout 被吞——用「写文件 + Read 工具读」模式执行命令；PowerShell 删除受 safe-delete 守卫（转 trash 失败即报错），临时文件用 Get-ChildItem -File | ForEach-Object Remove-Item 逐个删。

## EPUB 导出兼容性改造（按清单全部执行，已完成）

**根因（实测）**：论语导出书打不开 = 导入型扁平书被聚合成单个 1.53MB XHTML（spine=1，325 个目录锚点全指同一文件）；诗经原书 335 个文档最大 43KB。次因：1162 处 img 无 manifest 条目（data URI 透传）、CSS 全 var()、2.0/3.0 混合态、无发布前校验。

**已落地**（测试：exporter 70 / layout 89 / import 21 / import-epub 17 / 其余全绿；13 包 tsc + vue-tsc + demo build 全过）：
- `exporter-epub/src/sections.ts`：`splitSections` 体积兜底拆分——顶层标题（h1/h2）优先断点 + 256KiB 贪心装桶 + 超大结构节点按子节点递归拆（首桶保 id、续桶剥 id）；`buildNavItems(sections, anchors)` 签名变更。
- `exporter-epub/src/media.ts`（新）：`MediaCollector` data URI 解码入库 OEBPS/media/*、内容散列命名去重、`sniffImageMediaType` 嗅探校正 media-type、外链/blob/死链分级告警；`html-serializer.ts` 加 `rewriteSrc` 选项接入。
- `exporter-epub/src/validate.ts`（新）：epubcheck 规则子集（OCF/PKG/NAV/MEDIA/DOC/XML/CSS/SIZE 共 20 码）+ 轻量 XML 格式良好检查器（标签栈 + 属性引号 + DOCTYPE 内部子集扫描）；`exportEpub` 默认调用并经 `onValidation` 透出。
- 版本策略：默认 EPUB 3（properties="nav"、dcterms:modified、refines、opf:role、封面 cover-image），`version:'2.0'` 显式兼容（XHTML1.1 壳 + meta name="cover"）；xhtml.ts 双 flavor；ncx 两路均输出。
- `book-css.ts`：`flatten` 导出扁平化（删 :root、var() 替换为字面值，迭代替参支持 fallback 链）+ `-webkit-writing-mode`/`-webkit-column-count` 前缀。
- 元数据：`normalizeIdentifier`/`isIsbn`（裸 ISBN→urn:isbn:）、`contributorRoleCode`（古籍角色→MARC relator）；`import/src/title.ts`（新）`sanitizeBookTitle` 剥 z-library 系站点尾巴，demo ImportPanel 接入。
- demo App.vue：导出校验结果 → 工具栏状态行（error 红）+ console 分级输出。
- 文档：docs/07 重写、exporter-epub README 重写、功能完善增改清单 §2.2 勾选 + 新增 §2.7（含真机验证矩阵 5 项）。

**诗经端到端实测**（临时 e2e 测试，跑完已删）：导入 12614 顶层节点 → 导出 **328 节 / 最大 31KB / 中位 5KB / 17 张媒体全部打包 / 351 条目 / 校验 error=0 / data URI 残留 0**，与原书结构同构。产物存 `.workbuddy/tmp-diag/e2e/诗经-新导出.epub`（887KB）供真机验证。
