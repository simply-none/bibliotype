直排量尺改共享流容器（块间共享列，消除每页累计取整虚高）

**根因**（《少有人走的路》直排逐页审计）：量尺把每块独立包在 block div 里——
直排下每个 div 独立断列，块的 mainSize **向上取整到整列**；而真实页面是连续
行内流，块与块**共享列**（上块末列的残差由下一段填充）。每块虚高 ~0.5 列 ×
每页块数 = 页末 1~3 列空白，块越密越明显。

- **共享流量尺**：直排分支所有块的行内流 HTML 连续放入同一个 `.bt-vflow`
  容器（块包装器 `display: contents`，不产生盒），列高 / 字体 / 断列与真实
  页面完全同构；块的推进量取「相邻两块起缘差」（小数），块体尺寸取行盒
  联合跨度——与真实渲染逐像素同源。
- **直排末列下沉**：`resolveBottomSlack` 直排不再恒为 0——末列可伸入排文
  末端侧边距，最深距页码（直排侧置竖排）字形 3px，预算公式与横排同款
  （`边距 − 页码带 40 − 3`）。
- **直排标题不捆绑下段**（document-blocks）：keepWithNext 仅横排——古籍
  原义标题就是文首一句，随文连排、不与下段捆绑（捆绑时「标题+下段 ≥2 列
  放不下」整组挪页，制造 1~2 列空白）。
- **实证**（同一本书，古籍直排）：总页数 1382 → **1253**（连排 + 满版累计
  1608 → 1253，**-22%**）；页底空白直方图 79% 的页 ≤0.5 列，≥1 列的页仅剩
  页末残差（<1 列，装箱物理必然——下一段首列 30.4px 放不进剩余空间）。
