古籍直排连排：章节随文接排，不再强制另起页

**背景**：《少有人走的路》直排逐页校验——「第二章 浪漫」章首页仅排 60% 即
空白（章标题 h2 强制另起页 + 严格孤寡行把 3 行短段整段挪页）。横排的
「章起新页」是印刷惯例，古籍直排本无「页」的概念：卷 / 章 / 节随文连排、
靠低格 / 提行标记段界。

- **直排连排**（document-blocks）：axis 为 'column' 时——① h1/h2 标题不再
  强制另起页（横排惯例仅限 axis 'row'）；② 结构容器（卷 / 章 / 节 / 序 /
  跋 / 附录）的首叶不再另起页，仅**前后件**（封面 / 书名页 / 版权页 /
  封底）保持独立起页（书的物理件，与正文连排语义无关）。
- **古籍主题孤寡行放宽**（demo）：古籍直排 / 仿真直排预设改宽松 1/1
  （短段不再整段挪页，列底排满；引擎缺省仍为严格 2/2，印刷口径可配）。
- **实证**（同一本书）：古籍直排 1608 → 1382 页（章末空白全收）；「第二章」
  章标题随文连排、章页排满；普通正文页页底空白仅剩恒定网格余量与
  keepWithNext 标题整组挪页（标题不孤行的最小约束）两类。
