## 用户需求
为 bibliotype 做移动端 H5（手机浏览器 / WebView）UI 适配，先产出一份 **UI 改造清单 md 文件**（仓库根目录 `H5-UI改造清单.md`），便于后续按清单逐批执行。

## 产品概述
清单文件沿用 `P4-执行分批清单.md` 的成熟口径：进度总览 + 分批逐项勾选（现状问题 / 改造要点 / 涉及文件 / 验收标准）+ 执行约定 + docs 回写索引。本批**只产出清单文件本身，不实施组件改造**。

## 清单分批方案（基于已盘点的 24 个 vue 组件 + 13 个 demo 组件）
- **批 A（P0 阅读链路）**：demo App 移动布局（三栏 → 单列 + 底部导航）、BtBookView 窄屏单页模式与直排页宽/字号重标定、BtPager 触摸滑动翻页（直排方向反转）、BtToc/BtTocItem 抽屉化、BtSpreadLayout / BtCompareView / BtCollationCompare 窄屏上下堆叠降级
- **批 B（P1 编辑链路）**：BtEditor 软键盘与 visualViewport 视口适配、光标滚动跟随、demo 工具条固定底部与溢出折叠、BtSelectionReplaceMenu 触摸定位与选区手柄冲突、BtTableSizePicker 触控目标
- **批 C（P2 面板与工具）**：侧栏类组件（标注 / 建议 / 修订 / 版本）统一抽屉化、设置类面板（主题 / 统计 / 字库 / 加密 / 备份）全屏化、BtSidebarResizer 在 H5 禁用、BtBookShelf 单列网格、BtNotePreview 定位适配
- **批 D（P3 全局基建）**：断点体系（CSS 变量 + `useBreakpoint` composable）、触摸目标 ≥44px、safe-area 刘海屏、视口 meta 与缩放冲突、系统字号跟随、滚动锁定与橡皮筋（overscroll-behavior）、横竖屏 / 折叠屏、桌面端回归保障（断点不影响桌面默认行为 + 语义钩子供测试断言）
