## 产品概述

让书籍从「单一版心、固定页眉」升级为「可按章分栏、可自定义页眉页脚、可按场景隐藏内容」的排印底座，并把多栏从 CSS 假分栏变成真正的逐列装箱分页，同时支持左右对页阅读与手动分栏断点。

## 核心功能

- 章节可设置分栏数（1–3 栏），分栏设置在阅读、编辑、导出三端一致生效。
- 书级可定义页眉、页脚内容，覆盖默认的书名、章名、页码派生显示；同一本书各至多一个。
- 新增「条件内容」容器：按阅读平台（网页、EPUB、PDF）或读者角色（如教师）决定是否展示其中内容；未提供上下文时全部保留，保证既有产物不变。
- 多栏真分页：正文按列依次填满，列满进入下一列，整页列满才换页；长段落可在行处跨列续排，不再整块挪页留白。
- 多栏分页在屏幕上按列并排呈现，阅读进度与页码仍按整页计。
- 左右对页（facing）模式：奇数页与偶数页并排展示，页眉页脚沿用已有的奇偶页差异化能力，中缝留白可调。
- 手动分栏符：在段落之间插入断点，使后续内容从下一列开始；单栏文档插入后不产生版面变化。
- 文档结构校验与迁移补全：旧文档升级后视觉与导出结果保持不变。


## 技术栈

沿用现有栈，不新增第三方依赖：pnpm monorepo、TypeScript（strict / ES2020）、ProseMirror、Vue 3、vitest（node / happy-dom）、tsup、turbo、fflate。排印仍由 `@bibliotype/layout` 的纯函数分页器承担，不引入 Paged.js / Vivliostyle 等外部引擎。

## 实施方案

### 关键假设（本计划直接采用，不再单独确认）

- `columns` 上限保持 **3**，与 `packages/layout/src/layout-options.ts:100-102` 的「1~3」及 `metrics-signature` 现有口径一致，不扩到 4。
- 对页中缝复用 `LAYOUT_TOKENS.COLUMN_GAP`，不新增主题令牌，减少主题面变更。
- 条件表达式采用受控语法而非通用表达式引擎：`when` 为分号分隔的 `key=value` 合取，支持 `!key=value` 取反；键限定为 `platform` / `role`，值做白名单校验。非法值进入 `DocumentIssue`，不抛异常。
- 页眉页脚为 `book` 直接子节点，每本各至多一个；渲染时覆盖 `page-chrome` 的派生值，未定义时行为与现在完全一致。
- 分栏数写在 `chapter` / `section` 的 `attrs.columns`；`volume` 不参与继承（需要时后续扩展），文档写明。

### A6：IR 增加分栏 / 页眉页脚 / 条件内容

- 节点：`packages/core/src/ir/node-types.ts` 增 `PAGE_HEADER` / `PAGE_FOOTER` / `CONDITION`；`chapter` / `section` 的 attrs 增 `columns`（缺省不落库，读时按 1 处理，减少存量文档字节变化）。
- 求值：新增 `packages/core/src/ir/condition.ts`，导出 `ConditionContext`、`parseCondition`、`evaluateCondition`。求值是纯函数，缺省上下文返回 `true`。
- 校验：`validateDocument` 增三类规则——`columns` 越界、页眉页脚父级非 `book` 或重复、`when` 语法非法；新增 `DOCUMENT_ISSUE_CODES` 条目，全部以 issue 返回而非抛错。
- 迁移：`IR_SCHEMA_VERSION` 由 `0.1.0` 升到 `0.2.0`，在 `BUILTIN_MIGRATIONS` 增 `0.1.0 → 0.2.0` 步骤：仅提升版本号，并把越界 `columns` 归一为 1；不注入空页眉页脚，保证「迁移后序列化产物与旧版一致」。
- 编辑器：`packages/editor/src/core-node-specs.ts` 登记三个新节点（页眉页脚 `content: 'inline*'`，条件容器 `content: 'block*'`）；`commands.ts` 增 `insertPageHeader` / `insertPageFooter`（已存在则返回 `false`）与 `insertCondition(when)`；`index.ts` 具名导出。
- 序列化：`html-serializer.ts` 增标签映射（页眉 `div.bt-page-header`、页脚 `footer.bt-page-footer`、条件容器 `div.bt-condition` 带 `data-when`）；`condition` 在序列化时按上下文剔除不满足的子树，缺省上下文保留；`chapter` / `section` 带列数时输出 `data-columns`。
- 样式：`book-css.ts` 只加 `scoped()` 内的 `.bt-page-header` / `.bt-page-footer` / `.bt-condition` 与 `[data-columns]` 兜底规则，供 EPUB / 站点这类重排流使用；真实分页由 B4 消费 IR 列数，不依赖 CSS 分栏。

### B4：多栏装箱与对页

- 分页模型：`PaginatedPage` 增可选 `columns`（每列含 `items` / `usedMainSize`）；`page.items` 保持为各列拼接，`usedMainSize` 保持整页口径，向后兼容既有消费方。
- 容量分配：先按页底注扣减 `pageMainSize - noteMainSize`，再除以列数；余数给末列。注区仍按整页展示，文档写明「注区整页扣减、列容量均分」。
- 装箱：`paginate` 内按列推进，列满进下一列，全列满换页；行级拆分沿用 `lineRangeMainSize` 与 `sliceNodeByCharRange`；孤寡行规则按列生效。
- 量尺：`packages/vue/src/pagination-measure.ts` 与 `paged-editor/use-paged-layout.ts` 按列宽建量尺容器，移除「多栏 → 回退估算」分支；`BlockMeasureContext` 增 `columnWidth`，`metrics-signature` 把列宽算进去，列数变化触发一次重测。
- 对页：`LayoutOptions` 增 `spread: 'single' | 'facing'`（缺省 `single`）；`BtBookView` page 模式在 facing 下并排渲染「当前页 + 下一页」，舞台宽度为两页加中缝，奇偶页眉页脚复用现有 `headerEven` / `footerEven`；scroll 模式不套对页。
- 打印：`exporter-pdf/src/print-styles.ts` 增 `facing` 的左右页内边距镜像与中缝，`break-before: column` 同步进打印 CSS；EPUB 保持重排流。
- 兼容：`spread` 与 `columns` 都是可选新增，缺省产物与当前版本逐字节一致。

### C3：分栏符

- `break` 增变体 `column` 与常量 `COLUMN_BREAK_VARIANT`，新增 `insertColumnBreak` 命令；`core-node-specs` 允许该变体。
- 分页器识别 `MeasurableBlock.columnBreakBefore`，在列内提前终止当前列；`columns` 为 1 时忽略（命令仍可插入，语义保留，文档说明）。
- 序列化输出 `class="bt-break"` + `data-variant="column"`，`book-css` 增 `scoped` 的 `break-before: column` 规则，供重排流导出使用。

### 性能与可靠性

- 分页仍为单遍线性装箱，列盒只增加常数级写入，复杂度保持 O(块数)。
- 量尺是唯一 DOM 瓶颈：列数变化走既有「指标签名变化 → 重测一次」路径，不做逐列重复全量测量。
- 条件求值只遍历被序列化的子树，且不修改 IR。
- 迁移与校验全部返回 issue，不抛异常；导出前 `validateEpub` 仍按原有链路执行。

## 实施注意事项

- 两层注册必须同步：`core` 增节点后立刻改 `CORE_EDITOR_NODE_SPECS`、序列化标签与 `book-css`，并跑全量测试；只跑单包测试会漏「节点未登记」。
- schema 升版是高风险点：先落迁移与「旧文档迁移后校验通过、序列化产物不变」的回归，再动 B4；草稿与 IndexedDB 存量数据按迁移路径读取，不做破坏性重写。
- 样式只进 `scoped()`；页眉页脚沿用现有 `.bt-page-header` / `.bt-page-footer` 类名，避免与既有 chrome 样式分叉。
- 多栏渲染与量尺共用同一个列宽函数 `column-width.ts`，禁止在 Vue 与 layout 各写一份宽度公式。
- 分页器保持纯函数：不读 DOM、不读时间、不引入随机；列盒分配必须可单测。
- 确定性：迁移不写默认列数、不写空页眉页脚，保证同一输入迁移结果稳定。
- 测试环境：layout / editor / reader / exporter 用 node；vue 用 happy-dom，只断言结构与事件，像素级差异留给后续 e2e（I1）。
- 不做无关重构；P0 已交付的 `BtBookView` 注区、双指缩放、`fontSize` 接口不改签名，只做可选扩展。
- 完成 P1-a 后立即停止，汇报文件级清单、验证结果与一条提交文本，等待确认后再规划 P1-b（C10、E2、E4、F5、F6、K2、K4、K5）。
