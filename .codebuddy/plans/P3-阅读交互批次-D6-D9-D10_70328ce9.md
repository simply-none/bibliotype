## 用户需求

按《能力扩展实施计划清单.md》执行 P3 剩余批次，本轮只做 **K 系列三项：K3 句读/圈点自动标注、K6 缺字与异体字兜底、K7 典籍元数据规范**。D5 多形态阅读不进入本批（已确认下一批做全部五项：scroll-flow + 懒加载 + 锚点进度 + 翻页动效 + 双页对照）。

## 产品概述

让古籍编辑与出版链路闭环：把「断句、专名标注」从纯手工变成「规则/词典给建议 + 人工逐条确认」，把「生僻字/扩展区缺字」从静默豆腐块变成「IDS 合成占位 + 导出前缺字清单」，把「四部/版本/藏地/索书号」从散落在 `extra` 的备注升级为受校验的正式书目字段，并能导出 CNMARC 记录与 Dublin Core 数据。

## 核心功能

**K3 句读 / 圈点自动标注**

- 规则层：按句末虚词、疑问/感叹语气、列举结构生成句读候选（，。？！、；：）；识别《》书名并给出书名号标注建议
- 专名层：内置人名/地名/朝代/书名词典（纯数据、可扩展），并提供 `NameDetector` 端口供宿主接模型，不内置模型、不发网络请求
- 建议审阅：逐条展示类型、上下文、置信度；支持接受、拒绝、改类（逗号改句号等）、批量接受/拒绝
- 落盘策略：默认只在末字上加 `judou` 标记（不改正文字符），`attrs` 记录 `symbol / kind / source: 'auto' / confidence`；另提供「采纳为标点」命令，把建议一次性写成真实标点并清除标记
- 可逆性：接受/拒绝/采纳全部走编辑器事务，可撤销；全部拒绝时文档逐字节不变

**K6 缺字与异体字兜底**

- IDS 解析：支持 U+2FF0–U+2FFB 组合描述（如 ⿰山夆），容错未知运算符与超深嵌套
- 回退链：主字体 → 扩展字体链 → IDS 合成占位 → 方框；决策可注入字形探针，测试用假探针
- 渲染：按需把缺字替换为内联 SVG 组合字形占位（确定性输出、可缓存），默认关闭以保证既有产物零变化
- 缺字审计：扫描文档输出字符、Unicode 码位、是否私用区、所在节点路径与上下文；面板可点击定位
- 导出前提示：EPUB / PDF 各上报一次 `GLYPH-MISSING` 警告，不阻断导出

**K7 典籍元数据规范**

- 新增字段：四部细目（经/史/子/集 + 二级类）、版本类型（刻本/抄本/活字/稿本/石印/影印）、藏地（收藏机构）、索书号
- 校验：非法部类/版本类型/空值给出中文 issue，不抛异常；兼容 `extra.versionType / collection / shelfMark` 旧键迁移
- 映射导出：`toDublinCore` 输出稳定键序 JSON；`toCnmarc` 输出 CNMARC 文本记录（001/010/100/101/200/205/210/215/225/300/686/905 等字段与子字段）
- EPUB 补全：OPF 增加 `dc:subject`（四部分类）、`dc:type`（版本类型）、`dc:source`（藏地 + 索书号）、`dc:identifier`（CNMARC）、`dc:description`；EPUB 2 路径不输出 EPUB 3 专属 `meta property`
- Demo 接线：书籍信息弹窗可录入新字段，并可一键复制 DC JSON / CNMARC

## 视觉与交互基调

两块新面板沿用 `bt-` 命名空间与主题令牌，风格与既有 `BtThemePanel`、`BtFontFallbackPanel` 一致：建议列表用低对比卡片，置信度用细条；缺字格用等宽字位 + 红色角标；不新增全局选择器，过渡在 `prefers-reduced-motion` 下降级。

## 实施策略

沿用上一批已验证的分层：**纯函数内核 → 视图模型 → 薄组件 → 宿主接线**。三项互不耦合，可按 K3 → K6 → K7 顺序独立交付与回归。

关键决策与理由：

1. **句读用「末字标记 + CSS 伪元素」而非零宽标记**。ProseMirror 标记只能覆盖文本区间，不存在零宽 mark；把 `judou` 覆盖到「该句最后一个字」，CSS `::after { content: attr(data-symbol) }` 显示标点，IR 文本完全不变，拒绝时只需移除标记。序列化器现有 `default` 分支已把未知标记输出为 `<span class="bt-mark-<type>" data-*>`，因此 K3 只需加样式，不动序列化分支。
2. **句读建议与文字解耦，「采纳为标点」走编辑事务**。默认建议可逆；采纳时 `insertText(symbol)` + `removeMark`，复用编辑器撤销栈。导出侧不自动改写文字，避免"预览与保存不一致"；文档明确提示导出前可采纳为标点。
3. **专名识别走端口**。内置词典按最长匹配 + 词性/位置约束；`NameDetector` 仅定义接口，宿主可接模型；规则与词典是纯数据 + 纯函数，命中率可用固定样例锁定。
4. **IDS 只做「组合描述 → 占位字形」**。不引入 IDS 数据库，只解析 12 个组合运算符并递归合成 SVG；未知/超深直接退化为方框并记入缺字报告，不假装是真字形。
5. **字形替换默认关闭**。`serializeNode` 新增可选 `idsRendering`，只在显式传入 resolver 时输出 `<span class="bt-ids-glyph">`；默认路径字节不变，既有精确 HTML / 导出断言零影响。
6. **缺字采集复用 D10 的 `analyzeGlyphCoverage`**。不另造探针与报告结构；新增的只是「位置索引」（nodeId + 上下文）与导出警告适配。
7. **元数据只增字段、不改既有语义**。四部/版本用枚举 + 中文标签映射，`classification` 保留为自由字符串（可派生）；校验返回 issue 而非抛错；旧 `extra` 键提供只读迁移助手，避免破坏已有草稿。
8. **CNMARC 只出可读文本行**。不做 ISO 2709 二进制打包（无现成库、也不值得自研）；文本行便于人工核对与复制，字段/子字段顺序固定，输出确定。
9. **OPF 增量补字段**。`dc:subject / dc:type / dc:source / dc:identifier` 只在有值时输出，EPUB 2 路径维持现状；改 `opf.ts` 必须同步现有 XML 断言。

性能与可靠性：

- 缺字采集 O(文档字符数)，仅在导出 / 手动审计时执行，不进渲染热路径；结果按 `document` 引用 + 字体链签名缓存，避免连续导出重复扫描。
- 句读规则单段 O(n)，建议生成按段落节流（≥200ms），审阅列表虚拟化暂不做（单段建议量级 < 100）。
- IDS 解析与 SVG 生成按字符缓存 `Map<string, string>`，同字只算一次；SVG 为纯字符串拼接，无 DOM 依赖。
- 所有计时/存储/探针经参数注入，保证测试确定性与 SSR 可用。

## 执行要点

- `layout` 序列化默认 `default` 分支已输出 `<span class="bt-mark-<type>" data-*>`，`judou` 无需改序列化；**先验证**该分支对 `symbol/kind/source` 的输出顺序，再补 CSS。
- 新增书册 CSS 规则必须重锁 `classical-baseline.ts` 的 FNV，否则古典隔离测试必红。
- `serializeNode` 的 `idsRendering` 必须**缺省关闭**；开启时只替换「探针判定缺字」的码位，其余文本保持原样。
- `opf.ts` 改动会命中 EPUB 精确 XML 断言与 demo 导出快照，需同批更新；EPUB 2 路径不得新增 `<meta property>`。
