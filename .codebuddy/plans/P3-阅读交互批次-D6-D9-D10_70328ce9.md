## 用户需求

按《能力扩展实施计划清单.md》执行 P3 批次的**阅读交互三件套**，开发遵循《开发规范.md》与 README 既定架构。本轮只做 D6 / D9 / D10，D5 与 K 系列留待后续批次。

## 产品概述

让阅读器从「能翻页」升级为「可长期使用、可个性化、可深读」的阅读产品：目录能定位当前章节并支持折叠与检索，注释能从正文与注文双向跳转并即时预览，外观可通过主题令牌包自由导入导出与切换。三个能力均以 Vue 组件 + 纯函数内核 + 宿主注入持久化的方式提供，库内不写存储、不引入新运行时依赖。

## 核心功能

**D6 目录增强**

- 当前章高亮：随翻页/滚动自动更新活动目录项、`aria-current` 标记并滚入可视区
- 节点折叠：支持展开/收起、记忆展开状态、禁用态与键盘可操作性
- 目录内搜索：输入即过滤、命中项高亮、自动展开父级、清空即还原
- 章节缩略图：支持宿主传入缩略图（插槽/映射），无图时渲染首字占位骨架
- 侧栏拖拽宽度：拖拽调整、双击复位、方向键微调、宽度状态由宿主持久化

**D9 注释交互**

- 注码跳转：点击正文注码滚动/翻页到页底注或列尾注并高亮约 2 秒
- 注文回跳：点击回跳符回到正文原注码并高亮
- 悬浮/聚焦预览：桌面悬浮与键盘聚焦显示注文浮层，触屏点击触发，Esc 关闭、点击外部关闭
- 双向高亮：注码与注条同步激活态
- 上下条导航：快捷键在文档全部注释间循环切换，跳转跨页时自动翻页

**D10 主题与外观市场**

- 主题令牌 JSON 导入导出：带版本与类型标识，字段顺序确定，非法输入给出中文 issue 清单并拒绝
- 内置预设包：夜间、护眼、羊皮纸三套，并可注册扩展
- 字体回退链调试：逐字显示实际命中字体、缺字标红并给出 Unicode 码位
- 主题与样式预设解耦：主题只改令牌，切换预设不覆盖用户自定义字号与版式设置

## 视觉与交互基调

新组件沿用现有 `bt-` 命名空间与主题令牌（正文色、背景色、注文色、强调色），不新增全局选择器；目录活动态用左侧强调色条 + 加粗，搜索命中用淡黄底色，注释跳转用 2 秒渐隐高亮，主题面板以卡片 + 色板矩阵呈现，整体与现有阅读器一致、克制、无跳动。

## 技术栈

沿用现有仓库栈，不新增任何运行时依赖：

- `@bibliotype/core`：主题令牌、纯函数内核（主题包序列化/校验、字形覆盖分析端口）
- `@bibliotype/reader`：目录与注释的页级索引查询（复用既有 `pageByBlockId` / `indexNodeAnchors` / `page.notes`）
- `@bibliotype/layout`：注码 HTML 契约（`data-note-ref`）与书册样式激活态
- `@bibliotype/vue`：`Bt*` 组件 + `use*` 组合式（Vue 3 `script setup`，Vite lib + happy-dom 测试）
- `apps/demo`：宿主侧接线与 localStorage 持久化
- 测试：Vitest（happy-dom）；构建：turbo + tsup / vite；发布：changeset（fixed 列车）

## 实施策略

三个能力共用同一条分层：**纯函数内核（core/reader）→ 视图模型（vue 纯函数）→ 组件（薄视图）→ 宿主持久化（demo）**。

关键决策与理由：

1. **当前章节不走标题字符串匹配**。在 `reader` 新增按节点取页、按页取目录项的查询，基于既有 `pageByBlockId`（容器 id → 首叶页）与 `extractOutline` 结果索引；分页算法零改动，O(n) 预索引一次，查询 O(log n)~O(1)，不会在翻页热路径上重复遍历文档。
2. **状态外置，库内不写存储**。`packages/vue` 现状零 `localStorage`，折叠集合与侧栏宽度以 `props + v-model` 暴露，由 demo 落 `bibliotype-demo:` 前缀键，保持库的可测试性与 SSR 可用性。
3. **缩略图走插槽 + 占位**。仓库没有截图能力（E7 未做），强行引入 Canvas 截图会越界且不可测；改为 `#thumbnail` 插槽 + `thumbnails` 映射，缺省渲染首字骨架，后续 E7 落地可零改动接入。
4. **注释交互用事件委托**。注区与注码都是 `v-html` 注入，无法挂 Vue 监听；在 `.bt-reader-page` 上做单点委托，命中 `.bt-note-marker[data-note-ref]` / `.bt-note-backref` / `.bt-mark-noteref`，避免为每个节点绑定监听（1000 页文档下事件数恒定）。
5. **最小 HTML 契约改动**。仅给注码补 `data-note-ref`（与 `page-notes` 的 `data-note-id` 对齐），不重写注释序列化分支、不改 EPUB `epub:type` 语义；既有精确 HTML 断言同步更新。
6. **主题包做成可注册目录而非全局单例**。与 `NodeTypeRegistry` / 插件注册表口径一致（`createThemePresetCatalog`），避免包内隐式全局状态；令牌值校验保持「严于结构、宽于语法」（未知键与坏版本必拒，颜色/长度做基础格式校验）。
7. **字体回退判断走端口注入**。逐字命中依赖宿主字体能力，core 只定义 `GlyphProbe` 端口 + 纯函数 `analyzeGlyphCoverage`，vue 用 `document.fonts.check` 实现；测试注入假 probe，完全确定。

性能与可靠性要点：

- 目录视图模型由 `computed` 记忆化，仅在 `outline / query / expandedIds / activeKey` 变化时重建，O(n)；搜索使用预计算小写标题，避免每次输入重复 `toLowerCase`。
- 注释索引在文档加载时一次性建立（noteId → pageIndex），快捷键循环与跳转不做全文档扫描。
- 高亮计时器单实例、时长可注入（避免测试真等待）；`scrollIntoView` 在 happy-dom 缺失，必须 feature-detect。
- 主题序列化字段顺序固定、不含时间与随机值，保证快照可复现。

## 设计风格

延续现有阅读器语汇：以 `bt-` 前缀组件、主题令牌驱动、低对比纸感底色，新增交互只在状态反馈上做「克制而有感知」的强化，不引入新的视觉体系。

- **目录**：行高 30px，活动项左侧 3px 强调色条 + 加粗 + 轻微底色；折叠箭头用 12px 旋转三角，展开/收起 160ms 缓动；搜索框与目录同宽、无边框只在聚焦时描边；缩略图 40×56 圆角占位，缺图时显示首字与骨架竖线。
- **拖拽条**：4px 宽，hover/拖拽时扩展为 6px 并显示强调色，带 `:focus-visible` 焦点环。
- **注释**：注码点击后注条背景由浅强调色渐隐至透明（200ms 进入 / 2s 后 400ms 退出）；预览浮层为白底 8px 圆角卡片 + 轻阴影，最大宽 320px，超出视口自动翻转；缺字标红仅作用于调试面板，不污染阅读区。
- **主题面板**：两列色板卡片（背景色块 + 名称 + 当前态勾选），导入区为虚线拖放框，错误以红色条目列表就地展示；字体回退面板为等宽字符网格，缺字格红框 + 码位角标。

## 响应式

目录在窄屏（<720px）默认收起为抽屉式、拖拽条隐藏；预览浮层窄屏改为底部贴边卡片；主题面板单列堆叠。

## 动效降级

全部过渡在 `prefers-reduced-motion: reduce` 下改为无动画、仅切换终态。
