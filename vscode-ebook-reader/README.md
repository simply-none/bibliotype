# 电子书阅读器 VSCode 插件

在 VSCode 中阅读电子书，支持 epub/txt/html/md 格式。

## 功能特性

- 📚 **书库管理**: 侧边栏展示所有导入的电子书
- 📖 **多格式支持**: 支持 txt、html、md 格式（epub 格式需要后续版本支持）
- 🎨 **自适应布局**: 阅读界面自动适应窗口大小
- 📊 **阅读进度**: 自动记录阅读进度，下次打开时恢复位置
- 🌓 **多主题**: 支持亮色、暗色、护眼三种主题
- ⚙️ **自定义**: 可调整字体大小、行高等阅读参数

## 使用方法

### 导入电子书

1. 点击侧边栏的「电子书」图标
2. 点击书库视图顶部的「+」按钮
3. 选择要导入的电子书文件（支持 epub/txt/html/md）

### 阅读电子书

1. 在书库中点击电子书标题即可打开
2. 滚动阅读，进度自动保存
3. 下次打开时自动恢复到上次阅读位置

### 查看阅读进度

- 书库列表中每本书右侧显示阅读进度百分比
- 点击书籍可查看详细信息

## 配置选项

在 VSCode 设置中可以调整以下参数：

- `ebook-reader.fontSize`: 阅读字体大小（默认 16px）
- `ebook-reader.lineHeight`: 阅读行高（默认 1.8）
- `ebook-reader.theme`: 阅读主题（light/dark/sepia）

## 开发

```bash
# 安装依赖
npm install

# 编译
npm run compile

# 监听模式
npm run watch
```
