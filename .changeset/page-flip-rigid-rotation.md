翻页几何重构——edge 模式改**刚体旋转模型**（对齐云展网等硬页翻转观感）：

- **rotation 模型（捏边 / 中部滑动 / 自动翻页）**：整页绕书脊刚体旋转
  φ=π·R(p)（`geometry.flipAngleLag` 角度迟滞：两端减速、中段干脆），
  自由边带卷筒（`curlLiftAngle` 起翻掀角 / `curlFlightAngle` 飞行前缘
  卷角 / `curlRadiusLift`·`curlRadiusFlight` 卷筒半径），中段 sin^1.5
  飞行拱（`flipBowRatio`）避免 90° 侧立成线——页面立起、透视缩短、
  自由边最高点最后落桌，替代旧"卷筒+背面平摊桌面"的布感拖尾；
- **双页纸背真实纹理**：翻动叶的另一面贴目标侧面纹理（落地时与下层
  逐像素对齐，消除假纸背→内容突变），落定尾段纸背明度渐变至 1；
  单页模式保持暖调纸色 + 透字近似；
- **正反面按局部表面角判定**（过 90° 侧逐渐显背），落定淡出随纸背
  显现比例消隐；下层页投影改为随翻越投影范围移动的软影带
  （按所在侧门控，贴桌无影）；
- **节奏**：autoFlipMs 850→1150、微颤起点 0.6→0.82（落定页缘颤动）、
  fadeStart 0.85→0.88、snapMax 920→980；
- progress 语义不变（拖拽线性映射），决策阈值 / 橡皮筋 / 四向装订 /
  双页契约全兼容；角部捏角折角模型（fold）保留原实现；
  新增导出 `flipAngleFraction`。
